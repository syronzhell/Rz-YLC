v3.0.0 · SATU CMS

Kontrol judul live
dari satu dashboard.

Login YouTube, isi antrean, Start, dan Stop dari CMS. Pergantian judul berjalan di cloud. RDP cukup menjalankan encoder video yang sudah lo pakai.

Setup sekali

  1. Buat project Supabase, lalu jalankan supabase.sql di SQL Editor.
  2. Aktifkan YouTube Data API di Google Cloud dan buat OAuth Web application.
  3. Import folder project ini ke Vercel sebagai Next.js. Isi environment variables dan redirect URI sesuai README.md. Gunakan pembuat secret untuk membuat password dan kunci tanpa instalasi.
  4. Aktifkan System Environment Variables dan Fluid Compute di Vercel, lalu deploy.

Pakai sehari-hari

  1. Buka alamat CMS, login, dan klik Hubungkan YouTube.
  2. Mulai live dari RDP, lalu pilih live aktif di CMS.
  3. Masukkan A, B, C — satu judul per baris — lalu atur interval dan simpan.
  4. Klik Start Loop. Judul muter A → B → C → A.
  5. Klik Stop Loop saat ingin berhenti mengganti judul.

Tab CMS boleh ditutup. Siaran tetap berjalan setelah Stop Loop. Satu pergantian yang sudah dikirim ke YouTube bisa selesai saat Stop ditekan.

Ini source project, belum dideploy atau terhubung ke akun lo. Panduan lengkap ada di README.md. Hasil pengujian ada di VALIDASI.md.
